PharmacyFinder is an AI-ranked pharmacy locator prototype for Greater London. A user enters a postcode or address; the system returns ranked nearby pharmacies scored by proximity, walk time, and data quality — prioritising those most likely to be open and accessible.

The AI backend combines registry data, snap-quality scoring, and hours-confidence estimation to rank results. Uncertain results display confidence badges and data-anomaly flags so users always know how much to trust the output. When the system cannot produce a reliable answer, it explicitly abstains rather than guessing — a deliberate safety design choice.

Key features: walking-route map (OpenStreetMap), live confidence-threshold slider, graceful abstain state, and a sticky safety banner on every page marking it as a prototype not for clinical use.

What we'd improve next: real-time opening-hours verification via NHS API, accessibility routing, and coverage beyond Greater London.
